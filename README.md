# 长沙红中麻将 🀄

3 天极速开发项目。纯前端 JavaScript，单 HTML 页面，零依赖。

## 快速开始

```bash
# 直接用浏览器打开
open index.html
```

或部署到 GitHub Pages / 任何静态服务器。

```

```

## 胡牌算法

- **标准胡**：回溯法，N个面子 + 1个将眼
- **七小对**：7个对子（红中可替代）
- **碰碰胡**：全刻子 + 将对

红中万能牌在回溯过程中自动匹配。

## 长沙红中特色

- ✅ 红中万能牌
- ✅ 血战到底
- ✅ 扎鸟（翻牌倍率 ×2^N）
- ✅ 缺一色
- ✅ 天胡/地胡
