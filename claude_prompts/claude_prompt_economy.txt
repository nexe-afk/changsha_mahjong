# Claude 4.7 提示词 — 经济与内购系统
## 原模块: economy_system_prompts.json + monetization_prompts.json
## 原目标模型: gpt-4.1/codex → Claude 4.7

---

## 原提示词（Codex 版）关键内容

- 双货币系统: SoftCoin（软通货）+ PremiumGem（硬通货）
- Faucets/Sinks: 来源（签到/对局/任务）与消耗（商城/赛事报名费）平衡
- 通胀监控: M0供应量、F/S比率、基尼系数
- 经济模拟器: 蒙特卡洛模拟10000玩家30天
- IAP 内购: 13个商品（金币/钻石/房卡/皮肤）
- 广告变现: 奖励视频/插屏/Banner 频次控制
- 会员订阅: 月卡/季卡/年卡
- 任务系统: 每日/每周/里程碑
- 赛事系统: 每日/每周/巅峰赛

## Claude 4.7 优化版（压缩为2条）

### 01. 虚拟经济体系（合并原economy + IAP核心）

**Role**: 你是游戏经济系统设计师，精通双货币体系建模和 Faucets/Sinks 平衡设计。

**Task**: 为长沙红中麻将实现完整的游戏内虚拟经济体系。核心是 iaps.js 文件：双货币钱包（金币SoftCoin+钻石PremiumGem）、商城商品目录、购买流程和任务奖励系统。

**Context**:
- 语言: JavaScript ES6+，浏览器环境
- 存储: localStorage（前缀 mj_）
- 现有: account.js（用户管理）、gameState（玩家数据）

**Detailed Requirements**:

1. **双货币钱包**金币(coins)+钻石(diamonds)+房卡(roomCards)，汇率1钻石=100金币（单向）
2. **商城商品目录**13个商品：4档金币包（¥1/¥6/¥12/¥30）、4档钻石包（¥6/¥30/¥128/¥328）、3档房卡（¥3/¥10/¥40）、2个钻石皮肤（20/50钻）
3. **IAPManager**类: init/getItems/purchase/verifyPurchase/deliverItem/getPurchaseHistory
4. **每日签到**7天阶梯奖励（第7天500金币+3钻石）
5. **对局奖励**基础50金币+胡牌200+中鸟额外

**Constraints**:
- 所有价格以人民币元为单位
- 交易记录不可篡改（时间戳+签名校验）
- 免费货币和付费货币严格分离
- 每日金币获取上限5000，钻石上限50

**Output Format**: 文件 iaps.js（约250行），商品配置常量+IAPManager类。

### 02. 用户分层与留存变现（合并原推荐/订阅/赛事/社交）

**Role**: 你是用户增长和生命周期价值专家，精通用户分层运营和社交裂变策略。

**Task**: 实现玩家分层变现策略系统：根据玩家活跃度/付费行为/留存风险自动匹配变现策略。核心输出 segmentation.js。

**Context**:
- 语言: JavaScript ES6+，浏览器环境
- 数据源: localStorage 中的玩家行为日志
- 分层维度: 活跃度（7天登录天数）/ 付费行为（累计充值）/ 留存风险（登录间隔）
- 现有: account.js, iaps.js, ads.js

**Detailed Requirements**:

1. **用户分层**: 按活跃度（核心/常规/休闲/沉睡）+ 按付费（鲸鱼/海豚/小鱼/免费）+ 按留存风险（低/中/高/极高）

2. **分层变现策略**:
   - 鲸鱼(充值>¥1000): 限量礼包+无广告
   - 海豚(¥100-1000): 季卡+中型礼包+无广告
   - 小鱼(<¥100): 月卡+首充双倍+少量插屏
   - 免费(活跃): 首充引导+奖励广告
   - 沉睡: 回归礼包+抽奖召回

3. **激励触发**: 连败≥3局或连续5局未胡牌触发助力礼包（优先免费/看广告，付费是最后选项）

**Constraints**:
- 严禁「付费必胜」设计
- 挫败时优先提供免费帮助
- 每次激励触发冷却24小时
- 每日最多触发3次付费激励

**Output Format**: 文件 segmentation.js（约200行），包含 UserSegmentation 和 DDAMonetizationLink 类。
