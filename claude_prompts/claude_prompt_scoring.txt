## Claude 4.7 优化版

**Role**: 你是游戏数值策划师与赌台规则专家，精通麻将类游戏的得分模型、奖励曲线和牌型组合的数学倍数关系。

**Task**: 用纯 JavaScript (ES6+) 实现长沙红中麻将的完整奖励与经济计分系统。核心输出为 rule.js 文件，包含胡牌类型检测、倍数计算和扎鸟判定逻辑。

**Context**:
- 语言: JavaScript ES6+
- 接入接口: canWin(hand, zhong) 来自 hu.js
- 计分公式: 最终得分 = 牌型基数 × 扎鸟倍数
- 牌型可叠加，叠加时基数相乘
- 单局最高得分封顶: Math.min(finalScore, 1024)

**Detailed Requirements**:

1. **胡牌类型检测**:
   - pinghu（平胡x1）: 标准胡，N面子+1将眼
   - qixiaodui（七小对x2）: 7个对子
   - pengpenghu（碰碰胡x2）: 全刻子+将眼
   - qingyise（清一色x4）: 单一花色+红中
   - tianhu（天胡x8）: 发牌即胡
   - 返回 string[]，如 ['qingyise', 'qixiaodui']

2. **倍数计算**:
   - calcMultiplier: 牌型基数相乘×扎鸟倍数
   - 示例: 清一色七小对 = 4×2 = x8
   - 示例: 天胡中3鸟 = 8×(2^3) = x64

3. **扎鸟判定**:
   - isBirdHit(tile): 红中或1/5/9→true
   - 胡牌后翻4张牌，每中1鸟×2
   - 中N鸟=2^N倍

**I/O Contract**:
```
getHuType(hand: number[], melons: object[]) → string[]
calcMultiplier(huTypes: string[], birdMultiplier: number) → number
isBirdHit(tile: number) → boolean
calculateScore(hand: number[], melons: object[], birds: number[]) → number  // 封顶1024
```

**Constraints**:
- 与 core.js 和 hu.js 的接口保持一致
- 最终结果取整（Math.floor）
- 所有计分逻辑每条有中文注释说明
- 封顶后明确输出 Math.min(final, 1024)

**Output Format**: 完整 rule.js 文件（约100行），包含所有计分常量和函数，附带8个断言测试用例。

**Verification Plan**:
1. calcMultiplier(['pinghu'], 1) → 1
2. calcMultiplier(['qingyise','qixiaodui'], 1) → 8
3. calcMultiplier(['tianhu'], 8) → 64
4. calculateScore(..., 中4鸟) → ≤1024
5. isBirdHit(40) → true（红中）
6. isBirdHit(1) → true（条1）
7. isBirdHit(2) → false
8. isBirdHit(15) → true（筒5）
