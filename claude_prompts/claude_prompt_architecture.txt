# Claude 4.7 提示词 — 游戏框架集成（新增）
## 参考项目: majiang(Laya), nanoserver, Simple-Mahjong, qp
## 用途: 承接所有下级 prompt 文件的容器化架构指引

---

## 架构思路（参考成熟项目）

本项目由以下参考项目的架构设计提炼而来：

| 参考项目 | 可借鉴部分 | 本项目对应模块 |
|---------|-----------|--------------|
| **majiang (Laya)** (⭐596) | 完整H5联网麻将结构：客户端Laya3.x+服务端Node.js，房间管理+匹配+对局 | 客户端PixiJS替代Laya，服务端同理 |
| **nanoserver** (Go) | 生产级房间俱乐部系统、断线重连、支付集成、好友系统 | 社交/大厅/支付模块 |
| **Simple-Mahjong** (SpringBoot+React) | WebSocket通信+前后端分离+内存存储 | 通信层原型 |
| **qp** (Go微服务) | 多游戏整合+微服务拆分 | 未来多游戏扩展 |

## 项目整体架构

```
changsha_majiang/
├── index.html                    # 入口，加载PixiJS 8 CDN
├── css/
│   └── style.css                 # 大厅/商城/弹窗样式
├── engine/                       # 游戏引擎层（已有，不修改）
│   ├── game_engine.js            # PixiJS 应用 + 主循环
│   ├── scenes.js                 # 场景管理（PIXI.Container）
│   ├── tile.js                   # 牌面渲染
│   ├── animation.js              # 动画系统
│   ├── renderer.js               # 渲染桥接
│   ├── flow.js                   # 对局流程控制
│   └── sound.js                  # 音效管理
├── js/                           # 核心算法层（你生成的代码放这里）
│   ├── core.js                   # 牌定义与牌墙（参考 q_algorithm 编码风格）
│   ├── hu.js                     # 胡牌判定（参考 q_algorithm 判胡逻辑）
│   ├── rule.js                   # 计分规则（参考 q_algorithm 倍数叠加）
│   ├── ai.js                     # AI 策略（参考 mahjong-helper 评分+防守）
│   ├── difficulty.js             # 动态难度（参考 archer 多层决策因子）
│   ├── ai_logger.js              # AI 可解释日志
│   ├── gamefeel.js               # 游戏感增强
│   └── tutorial.js               # 新手引导
├── claude_prompts/               # Claude 4.7 提示词目录
│   └── ...（当前文件所在目录）
└── docs/                         # 项目文档
```

**数据流**:
```
用户操作 → scenes.js (PIXI事件) → game_engine.js (主循环)
  → js/core.js (牌操作)
  → js/hu.js (胡判定)
  → js/ai.js (AI决策)
  → js/rule.js (计分)
  → scenes.js (渲染)
```

**Output Format**: 此文件不生成代码，仅作为架构参考 README 的补充。请将此架构融入你生成的提示词背景中，确保每个子模块知道自己在架构中的位置。
