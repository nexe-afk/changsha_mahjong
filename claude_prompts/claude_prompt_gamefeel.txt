# Claude 4.7 提示词 — 游戏感增强 (Game Feel)
## 原模块: 08 (prompts_v2)
## 原目标模型: gpt-4.1/codex → Claude 4.7

---

## 原提示词（Codex 版）关键内容

- 牌面特效: 选中脉冲、出牌拖尾、碰杠闪光、胡牌闪屏
- 音效细节: 摸牌/出牌/碰/杠/胡/按钮/倒计时音效
- 动画缓动: easeOutBack、出牌抛物线随机化
- 视觉冲击: 胡牌大字动画、中鸟金色闪光、当前玩家高亮

输出: gamefeel.js (~150行)

## Claude 4.7 优化版

**Role**: 你是游戏交互特效工程师，精通 PixiJS 8 动画系统和 Web Audio API，专注于游戏手感（Game Feel）优化和微交互细节。

**Task**: 增强长沙红中麻将的操作反馈和游戏感。在已有 engine/animation.js 和 engine/sound.js 基础上叠加特效增强，不破坏现有架构。核心输出 gamefeel.js。

**Context**:
- 引擎: PixiJS 8 (WebGL)
- 现有动画系统: engine/animation.js（Anim 类）
- 现有音效系统: engine/sound.js（SoundFX 类）
- 方法: 在原型上添加方法或创建新函数，不修改原有方法签名

**Detailed Requirements**:

1. **特效增强**:
   - 选中脉冲：金色光圈 + 上浮 + 阴影放大
   - 出牌拖尾：alpha=0.3 的残影副本延迟50ms消失
   - 碰杠闪光：白色全屏闪屏100ms
   - 胡牌闪屏：金色闪屏200ms + 大字「胡！」弹出回弹动画
   - 中鸟提示：翻出1/5/9/红中时金色闪光

2. **音效补充（Web Audio API 合成）**:
   - 摸牌: 800Hz方波0.06s
   - 出牌: 600→400Hz下滑0.08s
   - 碰: 300-500-700Hz三角波三连音
   - 杠: 200-300-400-500Hz锯齿波四连音
   - 胡: 400-600-800-1000-1200Hz正弦波五连音上升

3. **动画参数**:
   - 统一 easeOutBack 缓动
   - 出牌抛物线高度 12-18px 随机
   - 碰杠收集动画时长 200-300ms 随机

**Constraints**:
- 所有增强通过函数覆盖或原型扩展实现
- 不修改 engine/ 目录下的现有文件
- flashScreen 和 showBigText 返回 Promise，支持 await

**Output Format**: 文件 gamefeel.js（约150行），包含 enhanceAnimations(), enhanceSounds(), flashScreen(), showBigText() 四个导出函数。
