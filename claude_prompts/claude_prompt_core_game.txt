## 专业背景与项目参考

**Role**: 你是资深麻将算法工程师，专注考察过以下开源项目的核心实现：
- **q_algorithm** (⭐2k+, GitHub: yuanfengyun/q_algorithm): 高性能胡牌/听牌判断库，支持任意数量赖子（万能牌），有 JavaScript 绑定。它的核心是 `canWin(hand)` 和 `ting(hand)` 两个函数，采用高效的组合枚举算法。
- **mjx** (nyantama0616/mjx): 高性能日麻框架，速度比常规实现快100倍，适合研究极致性能优化。
- **majiang (Laya版本)** (⭐596, GitCode): 基于 Laya3.x 引擎的完整联网麻将项目，包含完整的 core.js 规则实现。

**你的任务**：实现长沙红中麻将的核心游戏逻辑，但**不需要从零造轮子**。algorithms 参考 q_algorithm 的编码风格和判胡逻辑，架构参考 majiang (Laya) 的项目结构。

**Task**: 用纯 JavaScript (ES6+) 实现长沙红中麻将的完整核心游戏逻辑。运行环境为纯浏览器端前端算法模块，无服务端依赖。生成 core.js（牌定义与牌墙管理）、hu.js（胡牌判定与听牌检测）、rule.js（胡牌类型与倍数计算）三个文件。

**Context**:
- 语言: JavaScript ES6+（纯算法，无 DOM 依赖）
- 牌编码规则: suit*10 + value, 条=0 筒=1 万=2, 红中=40
- 牌墙: 112 张（条筒万各9种×4 + 红中×4）
- 长沙特色规则: 红中万能牌（替代任何牌）、血战到底、扎鸟翻牌、缺一色（最多两门花色）
- 调用接口: 引擎层通过 gameState 对象与算法层通信
- 核心要求: 纯函数式，不可变输入，不修改外部状态

**参考 q_algorithm 的关键设计点**:
1. 使用位运算编码牌型（q_algorithm 用 uint64 表示手牌，一个 bit 表示一张牌）
2. 胡牌检测先用牌型模式匹配（七小对→刻子顺子），而非纯回溯
3. 赖子（红中）在匹配时做「通配符展开」，q_algorithm 的处理是：先算基础胡，再把张数足够的牌型做赖子替换再计算
4. 听牌检测基于「输⼊一张牌看能否胡」的插⼊法

**不需要完全照搬 q_algorithm 的位运算**（JS 环境中可读性更重要），但要理解其「先匹配后枚举」的优化思路，并在你的回溯法中嵌入同样的优化：
- 先检查七小对（O(n) 即可判定）
- 再执行标准胡回溯：N个面子（刻子/顺子）+ 1个将眼
- 红中万能：在回溯中尝试替代任何牌
  - AA + H → AAA（刻子）
  - A + H + C → ABC（顺子）
  - A + B + H → ABC（顺子）
- 递归深度 ≤ 5 层

**Detailed Requirements**:

1. **牌定义与牌墙管理** (core.js):
   - encodeTile(suit, value)→number / decodeTile(code)→{suit,value,name}
   - createWall()→number[]（112张）
   - Fisher-Yates shuffle→number[]
   - deal(wall)→[hand0,hand1,hand2,hand3] 每人13张
   - 工具: countInHand, getCountMap, removeTiles, sortHand, findPairs
   - 全局 gameState 对象

2. **胡牌判定算法** (hu.js) — 参考 q_algorithm 的设计：
   - canWin(hand, zhong)→boolean: 先七小对→标准胡回溯，红中当万能牌
   - getTingCards(hand)→number[]: 遍历剩余牌库，逐张插入后调用 canWin
   - checkQueYiSe(hand)→boolean: 最多两门花色
   - drawBirds(wall, count)→{birds, multiplier}: 扎鸟翻4张，中1/5/9/红中=2^N

3. **规则判定** (rule.js):
   - getHuType(hand, melons)→string[]: 平胡/七小对/碰碰胡/清一色/天胡
   - calcMultiplier(types, birds)→number: 牌型叠加基数相乘×扎鸟倍数
   - 单局最高封顶 1024 分

**I/O Contract**:
```
canWin(hand: number[], zhong: number)    → boolean
getTingCards(hand: number[])             → number[]
drawBirds(wall: number[], count: number) → { birds: number[], multiplier: number }
getHuType(hand: number[], melons: object[]) → string[]
calcMultiplier(huTypes: string[], birdMultiplier: number) → number
```

**Constraints**:

- 每个函数头部有中文注释（功能/参数/返回值说明）
- 禁止第三方库和浏览器 API
- 禁止全局变量污染（gameState 除外）
- 递归深度 ≤ 5 层防栈溢出
- 完整代码输出，无 TODO 或省略号

**Output Format**: 三个文件 core.js（~150行）+ hu.js（~200行）+ rule.js（~120行），每函数均有中文文档注释。
